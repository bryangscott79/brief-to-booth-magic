The deck, slide by slide

Every layout in the typed slide system (src/lib/deckSpec.ts), rendered with real demo content — Samsung · CES 2027 · Exhibitus. Each board shows two rows: the Pitch style in an agency kit (Exhibitus navy) and a client kit (Samsung blue), then the Executive, Editorial, and Tactical presets on the agency kit. Same DeckSpec, same brand kit — only the style tokens (src/lib/deckStyle.ts) change, and both renderers (deckSlideHtml.ts for preview/PDF, deckBuilder.ts for .pptx) resolve the same tokens to the same geometry.
